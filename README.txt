PEMASANGAN (XAMPP/Laragon)
1. Salin folder ini ke htdocs (mis. C:\xampp\htdocs\buku-tamu-man-sorong).
2. Jalankan Apache + MySQL, buka phpMyAdmin > Import > pilih database.sql.
3. Sesuaikan kredensial DB di app/bootstrap.php bila perlu (bawaan: root tanpa password).
4. Pengguna/tamu : http://localhost/buku-tamu-man-sorong/
5. Admin         : http://localhost/buku-tamu-man-sorong/admin/login.php
   (kunjungan pertama = form membuat akun admin pertama)
Catatan: Excel berupa file .xls (tabel HTML) yang dapat dibuka di Excel; PDF lewat cetak > Simpan sebagai PDF.
